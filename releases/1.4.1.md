# CubeOffice 1.4.1

- 修复 Windows 安装后无法正常打开应用的问题。
- 改善 Word、Excel、PowerPoint 和 Visio 的字体显示，优先使用系统已安装字体，并在缺少字体时选择更合适的替代字体。
- 改善 Word 的行距、分页和 PDF 导出效果，修复横向文档比较时页面宽度不正确及滚动时页面背景错位的问题。
- 改善 Android 最近文档预览和演示文稿加载体验，全屏演示时隐藏系统栏，让更多空间用于展示内容。

## English

- Fixed an issue that prevented the Windows app from opening correctly after installation.
- Improved font rendering in Word, Excel, PowerPoint, and Visio, using installed system fonts when available and more suitable substitutes when fonts are missing.
- Improved Word line spacing, pagination, and PDF export. Fixed incorrect page widths when comparing landscape documents and misaligned page backgrounds while scrolling.
- Improved recent-document previews and presentation loading on Android. Fullscreen presentations now hide system bars to provide more room for content.
