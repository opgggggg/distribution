# CubeOffice 1.6.0

## 中文

- 改进 Word 表格的段落间距和默认单元格边距，使表格高度与分页更贴近 Word。
- 修复 AI 客户端连接时意外启动编辑器的问题，仅在实际操作文档时按需启动。
- 改进 macOS 的应用注册，减少“打开方式”菜单中的重复应用条目。
- 改进 Android PDF 双指缩放的稳定性。

## English

- Improved paragraph spacing and default cell margins in Word tables for more accurate table heights and pagination.
- Fixed the editor opening unexpectedly when an AI client connects; it now starts when needed for document operations.
- Improved macOS app registration to reduce duplicate entries in the Open With menu.
- Improved the stability of two-finger zoom in Android PDF viewing.
