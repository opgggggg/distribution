# CubeOffice 1.4.6

## 中文

- 标签页可以拖出成独立窗口，也可以拖回去重新排序，同时打开的文档数量不再有上限。
- 文档正在编辑时如果被其他程序改动，CubeOffice 会发现并在保存前提醒，不会悄悄覆盖对方的修改。
- Markdown 文档现在能显示 mermaid 流程图和 LaTeX 公式。
- 在 Word 和 PDF 里选中内容可以直接呼出操作菜单；首页的「连接 AI」按钮现在会直接打开连接设置。
- 修复 Windows 上无法调用系统打印的问题，修复 Word 目录中继承的标题编号、中英文混排时拉丁字母用错字体、以及文档比较时图片丢失的问题。
- 某个文档窗口出错不再影响其他已打开的文档；macOS 自动更新包不再携带多余文件，更新更可靠；更新说明会按你使用的语言显示。
- 手机和平板：没有网络时不再弹出模板和意见反馈的加载失败提示，离线使用更安静。

## English

- Tabs can be dragged out into their own window and dragged back to reorder, and there is no longer a limit on how many documents you can keep open.
- If a file you are editing changes on disk, CubeOffice notices and asks before saving, so neither copy is overwritten silently.
- Markdown documents now render mermaid flowcharts and LaTeX formulas.
- Selecting content in Word and PDF raises an action menu directly, and the home screen's "Connect to AI" button now opens the connection settings.
- Fixed system printing on Windows, inherited heading numbers in Word tables of contents, Latin text picking the wrong font in mixed-script paragraphs, and images disappearing from document comparison.
- A failure in one document window no longer affects other open documents, macOS update packages no longer carry extra files so updating is more reliable, and release notes now appear in the language you read.
- Phones and tablets: offline use is quieter — template and feedback panels no longer show network failure notices when there is no connection.
