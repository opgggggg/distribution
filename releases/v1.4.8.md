# CubeOffice 1.4.8

## 中文

- 改进桌面文档标签拖动，拖动时保留文档状态；Linux 统一在同一窗口中打开和切换多个文档。
- 改进 Word 交叉引用和题注编号引用，编辑文字时更好地保留域和引用结果的格式。
- 统一桌面对话框外观，滚动内容时保持标题和操作按钮可见，减少操作工具栏时意外选中文字的问题。

## English

- Improved desktop document tab dragging to preserve document state. Linux now opens and switches between documents within a single window.
- Improved Word cross-references and caption number references, preserving fields and reference result formatting when editing text.
- Unified desktop dialogs, keeping titles and action buttons visible while scrolling, and reduced accidental text selection in editor toolbars.
