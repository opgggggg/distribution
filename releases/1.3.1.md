# CubeOffice 1.3.1

- Android 新建演示文稿时可预览和选择模板。
- Android 底部导航更紧凑，文字格式面板重新设计，各编辑器面板的标题、关闭和操作样式保持一致。
- 修复底部面板被遮罩挡住、错误提示无法关闭，以及 Markdown 编辑器重复加载的问题。
- Android 恢复打开旧版 Word、Excel、PowerPoint 文件和图片，并完善从其他应用打开和分享文件。
- Word 支持在页面中编辑页眉页脚及其中的表格，比较文档时可更清楚地看到修改的文字。
- 改善 PowerPoint 图片、字体和主题颜色的显示。

## English

- Preview and choose a template when creating a presentation on Android.
- Enjoy a more compact Android navigation bar, redesigned text formatting controls, and consistent editor panels with easy-to-reach close buttons.
- Fixed blocked panel controls, errors that could not be dismissed, and repeated Markdown editor loading.
- Restored Android support for opening legacy Word, Excel, and PowerPoint files and images, including files shared from other apps.
- Edit Word headers, footers, and their tables directly on the page, and see changed words more clearly when comparing documents.
- Improved PowerPoint image, font, and theme color rendering.
