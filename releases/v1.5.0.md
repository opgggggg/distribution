# CubeOffice 1.5.0

## 中文

- 修复中文输入法在编辑器中的归属和交互问题，输入过程中的选区、恢复输入和公式样式都恢复正常。
- Word 排版更接近 Word：按字体计算行高、修正分节起始处的段前间距，跨页表格保持原有列宽。
- PDF 扫描件中的内嵌图片可正确解码提取；脚本叠加层预览失败时回退显示原始页面。

## English

- Fixed input method ownership and interaction in the editor, restoring selection, recovered input, and math run styles while typing.
- Word layout now matches Word more closely: per-font line boxes, corrected leading space at section starts, and split tables that keep their authored column widths.
- Embedded images in scanned PDFs decode correctly, and a failed script overlay preview falls back to the source page.
