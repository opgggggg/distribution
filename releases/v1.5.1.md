# CubeOffice 1.5.1

## 中文

- 修复 Word 段落跨页时最后一行不填满的问题，分页估算与实际渲染保持一致。
- 支持 Word 的 Ctrl+Shift+Space 插入不间断空格，并保证它在渲染时不被拆到两行。
- 修复 PDF 图片提取，改用文档打开时所用的编解码目录。

## English

- Fixed the last line of a page-spanning paragraph not filling, and aligned the pagination estimate with where the renderer actually breaks.
- Word's Ctrl+Shift+Space now inserts a no-break space, which stays together on the rendered line.
- Fixed PDF image extraction to use the codec directory the document was opened with.
