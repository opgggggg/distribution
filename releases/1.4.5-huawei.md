# CubeOffice 1.4.5 · 华为应用市场

鸿蒙版和 Windows 市场渠道于 2026-09-16 提交华为审核，两者都基于 1.4.5 发布源码
（`codex/release-1.4.5`，distribution `a7bc7a8`，upstream `b2f207b9`）。

## 鸿蒙（HarmonyOS）

- 版本 `1.4.5`，版本号 `1004005`，包名 `com.cubexp.office`。
- 构建：`APP_PROFILE=cubeoffice npm run build:web` + hvigor `assembleApp`
  （需要 `DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk`），再用
  `node scripts/sign-harmony-release.mjs` 以正式密钥签名。
- 私有产物：`~/cubexp.com/releases/1.4.5/CubeOffice-1.4.5-release.app`，82.00 MB，
  SHA-256 `8e85fe11b3bc9e29aab984a6109a4907d9ba8e0a6b57bced361a4d02fd38c8f3`；
  内层 HAP 与外层 APP 签名、Profile 一致性均通过校验。
- AGC：软件包合法性「已达标」，上架自检通过，软件包加密保持默认开启，发布区域
  中国大陆，2026-09-16 提交审核，状态「正在等待审核」。

## Windows（华为应用市场）

Windows 渠道的**首次上架**，应用为新建：APP ID `2040493232546124800`，软件包类型
EXE、支持设备 PC、应用名称与 DisplayName 均为 `CubeOffice`、分类「应用 / 商务」、
默认语言简体中文。

- 构建：`npm run desktop:build:win-x64:huawei`（1.4.5 源码 + 已合并的华为渠道），
  渲染层按市场渠道重建，不带自更新。
- 私有产物：`~/cubexp.com/releases/1.4.5/CubeOffice-1.4.5-huawei-windows-setup.exe`，
  18.43 MB，SHA-256 `24363c5fe246d247d1b72946d0d9b27ddf0528e7cb0a5e94f9f6261df67bb700`。
- 上架素材（同目录 `huawei-windows-listing/`）：216×216 图标，三张 1280×720 截图
  （首页、Word 编辑、演示文稿编辑），取自 Windows 虚拟机里运行的市场渠道安装包。
- 安装/卸载参数：静默安装 `/S`、默认安装路径 `/D=`、静默卸载 `/S`。

- 版权证书未提供：普通应用属非必选资质，若审核要求再补。
