Noto Sans CJK SC Regular is an unmodified portable CJK fallback for the Rust
notebook renderer. iOS's PingFangUI collection uses private outline tables that
the portable renderer cannot interpret. Fonts load on the rendering worker only
when a document contains text; ink-only boards do not initialize them.
