# OFD 规范实现与验证记录

实现基线是 **GB/T 33190—2016《电子文件存储与交换格式 版式文档》**。新生成的文件使用 `Version="1.0"`；读取器保留对现有文件中其他版本号的兼容行为。格式覆盖、图像互操作和正式一致性认证是不同的结论，本文件记录代码实际提供的能力及其边界。

## 宿主接口与渲染边界

- 数字签名的 `SignedValue` 是安全提供者返回的不透明二进制格式。标准第 18.2.4 节将其密码安全要求交由其他规范限定。因此 CMS/SES 封装、证书链、吊销、可信时间戳、硬件密钥等通过签名提供者接入；没有提供验证器时，结果明确为 `unverified`，不会将摘要一致当成签名有效。
- 视频、音频和 URI 动作由浏览器或 `actionHost` 执行。AVS 等浏览器不能解码的媒体需宿主播放器。窗口模式、操作系统截屏限制和持续打印份数管理也属于宿主应用职责；解析器完整暴露相应声明和权限检查接口。
- ICC 转换使用随包分发的 QCMS WebAssembly，也允许通过 `colorConverter` 更换色彩引擎。渐变在设备颜色空间采样，默认 192 DPI；原始 OFD 转换会按更高的输出倍率提高采样密度。已解析模型的后续导出沿用读取时生成的纹理。
- 内嵌 OpenType 字体通过轮廓呈现；缺少正确字体时不能从字形索引恢复其外观。可以通过 `fonts` 提供匹配字体。裸 CFF、损坏字体和额外图像编码并不被伪装成完整支持；对应诊断或 `decodeImage` 接口仍适用。粗体/斜体在缺少相应字型时使用合成样式。
- SVG/TXT/HTML/Markdown 导出和包级编辑均已提供。DOCX 是文字重建，PDF 双向转换是栅格转换；这些目标格式的转换保真度不是 OFD 结构合规性的证明。
- 本包尚未经过第三方完整一致性认证。尤其是全部设备上的字体替代、色彩精度和宿主播放/窗口行为，不能仅由本仓库的测试结果保证。

## 规范文本及 Schema

正文和规范性附录来源：

- [GB/T 33190—2016 扫描文本](https://github.com/ofdrw/ofdrw/blob/master/GBT_33190-2016_%E7%94%B5%E5%AD%90%E6%96%87%E4%BB%B6%E5%AD%98%E5%82%A8%E4%B8%8E%E4%BA%A4%E6%8D%A2%E6%A0%BC%E5%BC%8F%E7%89%88%E5%BC%8F%E6%96%87%E6%A1%A3.pdf)
- [Annex A 转录](https://github.com/wangxiaocuo/ofd-xsd)

`schema.ts` 只保留机器约束，去掉说明性注释，并合并 include，运行时无需联网取 Schema。转录中发现的遗漏已逐项对照扫描正文修正：Region 的线段/二次/三次贝塞尔定义、Movie/Appearance/Extensions 拼写、URI 的可选 Base/Target，以及注释的 Subtype/Print。修正代码保存在 `scripts/build-schema.py`。

标准正文与附录存在少量默认值/命名差异。例如正文表 21 的 MiterLimit 为 3.528，附录为 4.234；渲染默认取正文值，XSD 校验保留附录约束。自定义标引正文的 TypeID 与附录的 NameSpace 也不能混同。严格校验结果不会被兼容读取器的容错行为替代。

## 验证

49 项自动测试覆盖结构、签名篡改、ICC、字形映射、设备线宽、渐变/裁剪像素、字体样式、资源与版本、BMP/TIFF、动作及 Vue 生命周期。另以 28 份 OFDRW converter/reader 样例完成解析与全部 51 页 PNG 转换，包含发票、签章、缺资源和嵌套页块。

真实样例曾暴露原生渲染器对页面外文本的崩溃：现按页面边界剔除不可见对象，并将原生渲染放入可取消的子进程，底层故障不会终止调用方。两份缺少命名表的子集字体样例在修复后单独重跑通过。样例通过不表示所有可能的页面、设备或安全提供者均已完成验证。
