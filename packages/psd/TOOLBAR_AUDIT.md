# PSD 左侧工具栏审计报告

审计日期：2026-08-08

测试集合：`9348429.psd`（3556 × 2000 px，RGB/8，300 ppi）用于大图性能基线；`sample-layers.psd`（480 × 320 px）用于可重复的逐按钮浏览器验收。

参照：Adobe Photoshop 桌面版的工具栏、工具选项与画布手势逻辑。

## 审计标准

每个工具按同一套标准检查：激活态与快捷键、左侧工具选项、画布光标与手势、拖动中的实时反馈、一次操作对应一次历史提交、撤销、只读/锁定层反馈、键盘可访问性。

## 真实浏览器逐按钮复测

本轮使用浏览器原生鼠标点击/拖动逐个执行，不把“工具按钮能高亮”或“选项面板能打开”视为通过。每个会修改文档的工具还检查了 Undo 是否进入可用状态。

| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| Move                   | 背景层拖动后位置改变并可撤销；Title 左上角缩放由 `32,24 / 216×28` 变为 `20,12 / 228×40`，对象保持为 Title。 |
| Marquee / Lasso / Wand | 三种选区均产生不同的可视 overlay，并分别生成一次可撤销历史。                                                |

## 工具栏级 UI/UX

- 按 Photoshop 的工具族加入视觉分隔，按钮保留间距，不再挤成一列连续图标。
- 激活态使用克制的深灰底与左侧蓝色标记，不使用大面积浅色高亮。
- 上/下方向键循环焦点，Home/End 跳到首尾；所有按钮有快捷键说明与可见焦点。
- O 在 Dodge/Burn 间循环，G 在 Gradient/Paint Bucket 间循环；D 恢复黑/白默认色，X 交换前景/背景色。
- 工具详细选项只从左侧弹出，不触发右侧 Properties/Layers 面板联动，也不改变画布布局。
- 工具选项面板可用标题栏关闭按钮、Esc、再次点击当前工具或点击面板外关闭；关闭面板不退出当前工具，切换工具会重新打开对应选项。
- 右侧 Color/History、Properties 主面板及 Transform/Text/Document 小节分别持久化折叠状态，刷新后按用户上次布局恢复。

## 核心能力补充

- 选区 action 新增 `replace/add/subtract/intersect`，并以像素遮罩做可撤销组合。
- Magic Wand 和 Paint Bucket 新增非连续匹配；Bucket 新增透明度混合。
- Dodge/Burn 新增真实 tonal range 权重，不再把普通笔刷 opacity 假装成完整选项。
- 大图拖动与缩放继续采用 GPU 视觉预览，指针抬起后才运行文档 reducer 和历史记录。
- Overlay 不再在每次 pointermove 重设大画布；选区边缘缓存后复用，笔刷、套索、形状和渐变拖动不再反复扫描整张 3556 × 2000 遮罩。

## 已知边界

- Shape 明确采用 Pixels 模式；当前 PSD 核心还没有可编辑矢量形状层，因此没有伪装成 Shape Layer。
- Text 新建与重排可用，但字体由浏览器近似栅格化，不能保证与 Photoshop 字体引擎像素一致。
- Lasso 当前是自由套索，不包含 Polygonal/Magnetic Lasso；Crop 不包含透视裁切、拉直和生成式扩展。
- Clone 目前从当前层内取样；尚未提供 Current & Below / All Layers 取样模式。

这些边界都在 UI 中避免了误导性承诺，适合作为后续独立工具族继续扩展。
